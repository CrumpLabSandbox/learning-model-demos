Learning Model Demos

Models of associative learning are written as equations. These demos let you run each model one trial at a time and see exactly what each equation does: which numbers go in, which come out, and which term is responsible for each thing the model predicts.

Every model page works the same way. Pick a classic experiment, step through its trials, and read each equation four ways: in words, in symbols, with the numbers from the trial you selected, and as the code that ran. Then switch off one assumption at a time and see what breaks.

New to equations? Start here

Reading the equations walks through Δ, Σ, subscripts, the Greek letters, and the prediction error, with something to try at every step. It makes every model page easier to follow.

Models

  • Rescorla-Wagner (1972)

    Learning driven by a shared prediction error. Explains blocking, overshadowing, and conditioned inhibition, and fails on latent inhibition, backward blocking, and negative patterning.

  • Mackintosh (1975)

    Attention rises for the best predictor of the outcome. Coming next.

  • Pearce-Hall (1980)

    Attention follows recent surprise. Planned.

  • SOP (Wagner, 1981)

    Learning moment by moment, from what is active in memory. Planned.

  • MINERVA-AL (Jamieson, Crump, & Hannah, 2012)

    Learning without associations: store instances, retrieve an echo. Planned.
