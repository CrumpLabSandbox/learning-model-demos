About this site

Learning Model Demos lets students run classic models of associative learning one trial at a time and see how each equation produces what the model does.

In development

The site is still being built and checked. That means:

  • Pages, wording, and layout may change between visits.
  • Mackintosh, Pearce-Hall, and SOP are marked Preview. Their equations are tested, but their results have not yet been checked against the simulations in the original papers, so treat exact numbers with care.
  • Rescorla-Wagner is checked against its known mathematical results, and MINERVA-AL against the tables of simulation results in its paper.

If something looks wrong or is hard to follow, please say so on the project's issue page.

Who made it

Developed by Matthew J. C. Crump, Brooklyn College of CUNY.

The site was also implemented with Claude Code, Anthropic's AI coding assistant, working from Matthew Crump's plan and direction. Automated tests check each model against known results, and every page is checked in a real browser before it is published.

Each model is implemented from its original paper. The citations are at the top of each model page's code and in each model's overview slides.
