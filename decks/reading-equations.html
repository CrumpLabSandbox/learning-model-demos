Reading the equations: what to expect

How to read the rules that learning models are written in, one symbol at a time.

An equation is a recipe

In a learning model, an equation is an instruction: after each trial, change each cue's strength by this much.

The computer follows the same instruction on every trial. Each trial's result is the next trial's starting point.

You never have to solve it. You only need to know what each piece stands for.

This reframing helps anxious students: an equation is a procedure, not a puzzle.

Three kinds of number

experimenter

Set by the experiment: which cues appear and whether the outcome happens. Shown in green.

parameter

Chosen by the modeller before training, such as how fast learning is. Shown in purple.

computed

Worked out by the model on every trial: the predictions and the changes. Shown in pink.

Asking "who sets this number?" answers most questions about an equation.

Five symbols cover almost everything

Δdelta: "change in". ΔV is how much V changes on a trial.
Σsigma: "add up". ΣV is the strengths of the cues present, added together.
αalpha: how noticeable a cue is.
βbeta: how fast the outcome teaches.
λlambda: the outcome. 1 if it happens, 0 if not.
V itself is just "strength". The primer has a pronunciation table; saying the names aloud helps.
