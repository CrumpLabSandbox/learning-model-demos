All models

The models in course order. Each card says the idea in one line and what the model is known for getting right and wrong. Open a model in Essentials for the guided view, or Everything for the full trial table, the code, and custom designs. Every model has overview slides that say what to expect before any equations.

To see which model explains which finding, use the table on the start page, or run one experiment through several models at once on the comparison page.
